# Фотографии из Figma

Экспортируйте оригинальные фотографии из файла Pet-project (Page 3) в JPEG и положите сюда:

- `japan-guide.jpg` — фото в блоке «ВЕСНА В ЯПОНИИ» на главной и в гиде.
- `japan-destination.jpg` — фотография Японии в «Популярные направления».
- `place-1.jpg` — Храм Сэнсо-дзи.
- `place-2.jpg` — Район Сибуя.
- `place-3.jpg` — Рынок Цукидзи.
- `place-4.jpg` — Гора Фудзи.

В Figma выберите фотографию (не весь экран), справа Export → JPG → Export. Переименуйте по списку выше. После сохранения браузер Vite обновится автоматически.

Важно: здесь нет исходных изображений. Ссылки Figma MCP временные и не должны оставаться в проекте.
