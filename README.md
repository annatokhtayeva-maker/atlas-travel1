# Atlas — веб-приложение для планирования поездок

## Запуск на Mac

```bash
npm install
npm run dev
```
Откройте http://localhost:5173/

## Публикация на GitHub Pages

1. Создайте **публичный** репозиторий с точным названием `atlas-travel` на https://github.com/new.
2. Загрузите **содержимое этой папки** в корень репозитория (не вложенную папку).
3. В Settings → Pages выберите **GitHub Actions** как Source.
4. После выполнения workflow в Actions откройте `https://ВАШ-ЛОГИН.github.io/atlas-travel/`.

В репозитории должен присутствовать `.github/workflows/deploy.yml`.
При обновлении `main` сайт будет публиковаться автоматически.

## Изображения

Шесть JPEG-файлов уже лежат в `public/assets` и работают без интернета.
**Важно:** это иллюстративные изображения, сгенерированные ИИ и обрезанные из демонстрационной композиции; **это не оригинальные фотографии из Figma**. Для точного соответствия дизайну замените их экспортами из Figma, сохранив имена файлов.

## Технические детали

React, TypeScript, Vite, HashRouter (для корректной навигации на GitHub Pages), localStorage (данные сохраняются в браузере, без серверной синхронизации).
